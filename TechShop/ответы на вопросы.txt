1. Для чего нужен JavaScript?
JavaScript нужен для того, чтобы сделать веб-страницу интерактивной: реагировать на действия пользователя (нажатия кнопок, ввод текста) и динамически изменять содержимое страницы без её перезагрузки.
2. Как подключить внешний файл script.js?
С помощью парного тега <script src="script.js"></script>, который обычно размещают в самом конце тега <body> перед закрывающим </body>.
3. Что такое DOM?
DOM (Document Object Model — объектная модель документа) — это представление HTML-страницы в виде дерева объектов, с помощью которого JavaScript может находить элементы и управлять их содержимым или стилями.
4. Для чего нужен querySelector()?
Метод document.querySelector() ищет и возвращает первый элемент на HTML-странице, который соответствует указанному CSS-селектору (например, #buy или .product).
5. Что такое событие click?
Это событие, которое возникает в браузере в тот момент, когда пользователь нажимает левой кнопкой мыши (или касается на сенсорном экране) на какой-либо элемент страницы.
6. Что делает addEventListener()?
Этот метод «привязывает» к выбранному HTML-элементу обработчик события — функцию, которая автоматически выполнится, когда произойдёт указанное событие (например, click).
7. Зачем используется textContent?
Свойство textContent используется для получения или замены обычного текстового содержимого внутри HTML-элемента.
8. Почему сообщение появляется только после нажатия?
Потому что код изменения текста помещён внутрь функции-обработчика события click. При загрузке страницы браузер только запоминает эту инструкцию, а выполняет её исключительно в момент клика по кнопке.
9. Чем отличаются селекторы #buy и .product?
Символ # (решётка) обращается к элементу по его уникальному идентификатору id="buy", а символ . (точка) обращается к элементам по имени класса class="product".
10. Что произойдёт, если указать несуществующий id?
Метод querySelector() вернёт значение null (пустоту). При попытке вызвать у null метод addEventListener() или свойство textContent в консоли браузера появится ошибка (TypeError: Cannot read properties of null), и выполнение скрипта прервётся.
